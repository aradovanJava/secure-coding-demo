🛡️ Secure Coding Demo

Demonstracija XSS ranjivosti i zaštite u Spring Boot aplikaciji

📚 O ovoj aplikaciji

Ova aplikacija demonstrira razliku između ranjive i sigurne implementacije validacije korisničkog unosa.

⚠️

Ranjiva verzija

Nema validacije niti sanitizacije unosa. Omogućava XSS napade!

  • ❌ Bez @Valid anotacije
  • ❌ Bez sanitizacije HTML-a
  • ❌ th:utext izvršava JavaScript
Testiranje ranjive verzije

🎯 Primjer napada:

<script>alert('XSS')</script> <img src=x onerror="alert('Hakiran!')">
✅

Sigurna verzija

Koristi višeslojnu zaštitu protiv XSS napada.

  • ✅ @Valid validacija
  • ✅ OWASP HTML Sanitizer
  • ✅ th:text escaped output
  • ✅ Server-side provjere
Testiranje sigurne verzije

🔧 Tehnologije

  • Backend: Spring Boot 3.2, Java 17
  • Frontend: Thymeleaf Template Engine
  • Validacija: Jakarta Bean Validation
  • Sanitizacija: OWASP Java HTML Sanitizer
